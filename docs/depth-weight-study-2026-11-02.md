# 深度权重与低不透明度检查（2026-11-02）

本轮针对深度项量纲、低不透明度梯度、前端候选框坐标以及深度导出命名进行修复和验证。保留 LocalRF 的局部场表示、采样、窗口调度和米制深度 L1；没有新增优化目标。

## 结论与代码行为

- 用法示例改为 `depth_weight=0` 的光度加位姿先验基线。211 的本次短预算支持先比较 `1e-4～1e-3`，不能将它们当作整序列最优权重；`0.1` 在本次密度及位姿梯度中占主导。
- 新增默认关闭的 `--grad_log_every`，记录同批样本上各加权损失对活动参数的梯度范数。新增 `--seed`，在 `reconstruction()` 内统一设置 Python、NumPy、PyTorch 种子并写入导出元数据。
- 保留深度分母下限 `1e-8`；不默认提高下限、加裁剪或 opacity 观测门控。实际场压力测试未出现独立权重玩具模型那样的参数梯度放大，但不能排除其他场状态或训练过程中的尖峰。
- `prepare_fusion_points()` 用完整 `T_body_lidar` 把候选点转到载体系，再检查 x/y/z；2～35 m 范围仍按原 LiDAR XY 径向距离筛选。固定的前方框仍是数据集几何启发式，不是动态目标识别。
- `render_depth()` 改名为 `render_depth_moment()`，返回 `M=Σ(field_blend × Σ(w·z))` 和 opacity；tracking 的 M 单位为米，尚未除以 opacity。`expected_depth()` 再做归一化和导出阈值处理。代码从模型的钳位深度反求 M 时乘 `max(A,1e-8)`，避免在 A 小于下限时再次缩小分子；改名不改变导出结果。

## 211 权重对照条件

- 环境：Linux x86_64、PyTorch 2.15.0+cu132，CUDA 不可用；CPU 线程数 2。单组训练子进程耗时 16.8～28.1 秒（包含初始化和保存），十组总计约 204.7 秒；不含评估和脚本管理耗时，也不是性能基准。
- 数据：仓库内 `211/` 前 8 帧 `[0,8)`，无跳帧，1920×1200 下采样 8 倍为 240×150。显式轨迹 `211/meta/estimate_pose.tum`；没有重估 tracking、读取 GT 或更改输入数据。
- 深度：已有 uint16 PNG，`depth_scale=0.01 m`；统一光度权重保留观测遮罩，深度采用正值且有限的有效观测。
- 两个种子 `20211202`、`20211203`，每个种子比较 λ=`0,1e-4,1e-3,1e-2,1e-1`；相同种子下除 λ 和输出目录以外的参数一致。
- 固定 64³ 网格、一个局部场、8 帧同时初始化；每帧细化预算 40，`n_iters_reg=0`，`add_frames_every=1`，每组实际完成 321 次循环。这个配置隔离 λ 的影响，没有触发切场或上采样。
- batch=256，R=8 m，位姿学习率旋转 `1e-4`、平移 `2e-4 m`，先验 λ_t=`0.0156`、λ_r=`1`。固定内参，关闭曝光、密度 L1、TV，全部帧训练；保持其他默认值。
- 每 20 步记录一次梯度（0,20,…,320，共 17 次）。RGB 项已乘 0.25，深度项已乘 λ，先验项已乘各自 λ。组内记录 L2、最大绝对分量以及参数数量；不把不同单位的组混成一个总数。
- 最终评估为每帧同一组 2048 个不重复像素，共 16384 条射线，采样种子 `20261102`；无渲染抖动。所有配置使用相同像素、图像、观测深度及有效像素规则。λ=0 训练不加载深度，但评估仍读取深度。这里的评估是**训练视图拟合检查**，不是留出评估。

复跑单组（替换 `--logdir` 为新的目录；改变 λ 时同时保留基线，第二个种子改为 20211203）：

```bash

  --datadir ./211 --trajectory ./211/meta/estimate_pose.tum \
  --logdir /path/to/new_depth_study_run \
  --subsequence 0 8 --frame_step 1 --downsampling 8 \

  --add_frames_every 1 --batch_size 256 --N_voxel_init 262144 --N_voxel_final 262144 \

```

## 最终训练视图损失

下表是两种子的算术均值。最后一列先在各次运行内取比值，再对种子平均；它不是训练全过程的比值。

| λ_depth | RGB 项（含 0.25） | 深度 L1 / m | λ×深度 L1 | 加权深度/RGB |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 0.009993 | 28.4839 | 0.000000 | 0.00% |
| 0.0001 | 0.010693 | 1.1385 | 0.000114 | 1.07% |
| 0.001 | 0.010565 | 0.1118 | 0.000112 | 1.06% |
| 0.01 | 0.010644 | 0.0888 | 0.000888 | 8.34% |
| 0.1 | 0.010659 | 0.0889 | 0.008886 | 83.37% |

λ 从 0.001 提高到 0.1 时，深度 L1 的均值仅从约 0.112 m 降到 0.089 m，同时最终光度项略升。所有启用深度的配置，其光度项都高于同种子的无深度基线。只能据此描述本预算下的训练拟合权衡，不能证明深度质量或轨迹精度提高。

按审查提供的某步 `rgb_loss=0.0118`、`depth_l1_m=8.65`，若只令标量相等，λ≈`0.0118/8.65=0.00136`；若深度占 RGB 的 10%～100%，则 λ≈`1.36e-4～1.36e-3`。这不等于梯度平衡：残差下降后 L1 的导数并不随残差幅度成比例变小。

## 实际参数梯度

下表为 `||∇(λ L_depth)||₂ / ||∇L_RGB||₂`，每次运行先取 17 个诊断时刻的中位数，再对两个种子取均值。只比较同一参数组；分母为 0 的时刻不参与比值。λ=0 没有深度反传，记为 0。

| λ_depth | 密度组 | 旋转组 | 平移组 |
| ---: | ---: | ---: | ---: |
| 0 | 0.000 | 0.000 | 0.000 |
| 0.0001 | 0.163 | 0.080 | 0.055 |
| 0.001 | 0.686 | 0.646 | 0.309 |
| 0.01 | 5.852 | 5.425 | 3.216 |
| 0.1 | 64.986 | 56.234 | 29.670 |

λ=0.1 时，密度/旋转/平移上的深度梯度约为光度项的 65/56/30 倍；λ=0.001 时约为 0.69/0.65/0.31。即使最终加权深度标量只有 RGB 的约 1%，深度仍可产生可观的参数梯度。外观参数不影响深度，因此本实验深度对外观组的梯度为 0。

`grad/{rgb,depth,pose_prior}/{group}_l2`、`_max` 保存各项**实际范数**，不是只保存比值。诊断只包括当前会更新的密度、外观、位姿以及可选曝光/内参；首帧零学习率、旧场参数和旧场所属位姿排除。通过 `autograd.grad(..., retain_graph=True)` 获取，不写 `.grad`，不改变原有反传和 Adam 步骤。开启诊断会增加计算和临时内存开销；默认间隔 0 关闭。

这些是优化器前的梯度范数，不能直接等同于实际步长。参数组大小、窗口长度、密度参数化、学习率与 Adam 状态都会影响更新；范数也不能说明不同损失的梯度方向是否冲突。

## 低 opacity 压力检查与处理决定

设场内采样深度 z 使用场单位，场半径为 R，`A=Σw`，`D=R·Σ(wz)/max(A,ε)`，ε=`1e-8`。当 A>ε 时：

```text
∂D/∂w_i = (R z_i − D) / A
```

若 z 已经是米，则为 `(z_i−D)/A`。A<ε 时分母是常数，导数变为 `R z_i/ε`；钳位点处不可直接沿用上方分支的公式。独立权重测试确实出现 1/A 放大：米制 z=[1,5]、两个等权重时，A=0.5/0.01/2e-8 对应最大绝对导数约为 4/200/1e8。这里不是对场参数的导数。

实际 TensoRF 检查固定种子 `20261102`、64³ 网格、两分量因子、小型颜色网络、R=8 m、8×6 射线、第二帧偏心平移 `[0.15,0.1,0.05] m`，无抖动；目标深度均为 3 m，改变 `density_shift`，其他初始系数一致。下表是**未乘 λ 的原始深度 L1**对实际活动参数的梯度；提高下限一列只检查同一场的前向结果，不另行训练。

| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| -5 | 0.997 | 39.0616 | 39.0616 | 0.268903 | 0.373045 | 0.0312329 |
| -15 | 0.000262 | 94.4649 | 94.4649 | 0.434073 | 1.68095 | 0.0100988 |
| -23 | 8.78e-08 | 94.468 | 0.08432 | 0.43409 | 1.68103 | 0.010098 |
| -25 | 1.19e-08 | 94.468 | 0.0114115 | 0.43409 | 1.68103 | 0.010098 |
| -27 | 1.61e-09 | 15.4437 | 0.00154437 | 0.272388 | 0.898616 | 0.00656892 |
| -35 | 5.39e-13 | 0.0051808 | 5.1808e-07 | 9.13761e-05 | 0.000301453 | 2.20363e-06 |

A 从约 2.6e-4 降到 1.2e-8 时，此固定场的参数梯度保持同量级。softplus、alpha 和透射率的链式导数参与了结果，不能把独立 w 的导数直接等同于训练参数梯度。测试仅针对这一参数化和状态；它既不是全局梯度上界，也没有模拟密度塌缩全过程或检验 Adam 二阶矩受尖峰影响后的恢复时间。

因此保留 ε=`1e-8`：提高到 `1e-4` 会把同一固定场的约 94.5 m 深度改成 0.011 m，已经改变前向目标。也不默认按 A 筛除高误差观测，避免低不透明度使观测退出监督。没有凭单个固定测试增加裁剪阈值；用 `train/depth_low_opacity_fraction` 和按项参数梯度发现实际异常，再以对照实验决定是否需要约束。低于当前下限时输出同样已偏离严格条件期望，这一限制仍保留。
